# LimitLap

> **As fast as the field can hold.**

Браузерная 3D-гонка антигравитационных машин на магнитных полосах. Руля нет:
управляешь только скоростью и ищешь предел, который поле ещё способно
удержать в повороте. Одна попытка — 30–90 секунд, играется одной рукой на
телефоне.

- Честная физика: на внешней полосе поворота предел выше, но путь длиннее.
- Зона на грани: самый быстрый проход — у самого предела, где машину уже
  заносит.
- Ghost-заезды, вызов другу ссылкой, телеметрия круга.

## Стек

TypeScript, Three.js, Vite. Одна детерминированная симуляция для клиента,
сервера и тестов.

## Разработка

Нужны Node 24 и pnpm 12.

```sh
pnpm install          # зависимости всех пакетов
pnpm test             # тесты
pnpm test:coverage    # тесты с покрытием пакетов
pnpm test:browsers    # эталонные реплеи в Firefox и WebKit
pnpm golden:update    # пересоздать эталоны, если физика изменена намеренно
pnpm lint             # ESLint
pnpm typecheck        # проверка типов во всех пакетах
pnpm format           # Prettier
pnpm build            # сборка
```

| Пакет             | Назначение                  |
| ----------------- | --------------------------- |
| `apps/web`        | клиент                      |
| `packages/sim`    | детерминированная симуляция |
| `packages/tracks` | формат трасс и геометрия    |
| `packages/replay` | формат реплея               |

Пакеты подключаются друг к другу по имени (`@limitlap/sim`) прямо из
исходников на TypeScript, без отдельной сборки.
